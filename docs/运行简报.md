# miit_gxbcode 运行简报

> 项目定位：工信部《道路机动车辆生产企业及产品公告》新产品公示的**数据抓取 + 格式转换**工具。
> 数据流：`公告URL → miit_gxb_<批次>.csv → mj_gxb_<批次>.csv`。纯 CSV 管线，不碰数据库。
> 本简报为首次建立（2026-08-17）。

## 一、项目主流程 / 子流程

### 主流程（一键）

```
输入：公告页 URL（脚本顶部配置区 URL=，或命令行 python miit_crawler.py <URL>）
  │
  ▼
[1] miit_crawler.py  ──►  输出 output/miit_gxb_<批次>.csv（52 列，utf-8-sig 带 BOM）
  │                           │
  │                           ▼（自动，除非 --no-mj）
  └─────────────► [2] mj_convert.convert_csv ──► 输出 output/mj_gxb_<批次>.csv
                                                （48 列，全字段双引号 + 无 BOM + CRLF，与库导出格式一致）
```

### 子流程 1 · 爬虫（`miit_crawler.py`，7 步）

| 步骤 | 输入 | 处理 | 输出 |
|---|---|---|---|
| 1 | 公告页 URL | 解析 iframe，定位批次列表页 | 列表页 URL |
| 2 | 列表页 HTML | 提取数据接口 queryData + unitUrl | 接口配置 |
| 3 | 列表页 URL / 公告页 HTML | 正则识别批次号 | 批次号 |
| 4 | 数据接口 | 分页拉取第一层列表（企业名称/商标/名称/型号 + 详情链接） | 列表 rows（按原始顺序编号） |
| 5 | 详情页 URL | 并发抓取第二层，解析 4 张表（基本信息/技术参数/底盘/发动机） | 52 列明细 |
| 6 | 失败详情页 | 2 轮补抓重试 | 恢复的明细 |
| 7 | 全部明细 | 按链接去重 + 排序 + 拼装 | **`output/miit_gxb_<批次>.csv`**（52 列，utf-8-sig） |

参数：`--concurrency`(8) / `--retries`(3) / `--limit`(调试) / `--output` / `--no-mj`。
依赖：requests、beautifulsoup4、lxml（`requirements.txt`）。

### 子流程 2 · 转换（`convert_to_mj.py` + `mj_convert.py`）

| 输入 | 处理 | 输出 |
|---|---|---|
| `output/miit_gxb_<批次>.csv`（52 列） | 52→48 列：插 pici 批次标识、丢弃 企业名称_链接/产品商标1/产品型号1/产品名称1/企业名称1、技术参数列补单位后缀、底盘ID 置空 | **`output/mj_gxb_<批次>.csv`**（48 列，全引号 + 无 BOM + CRLF） |

用法：`python convert_to_mj.py`（自动取最大批次）/ `python convert_to_mj.py --batch 410`。
缺列 / 行宽异常抛 `ValueError`。

### 子流程 3 · 校验（`validate_output.py`）

| 输入 | 检查项 | 输出 |
|---|---|---|
| `miit_gxb_410.csv`（对照参考 `miit_gxb_409.csv`） | 表头一致 / 行宽 / 链接唯一 / 各列填充率 / 方向把(摩托车)抽样 | 控制台报告 |

## 二、更新调整内容

### 2026-08-17 · 新增「车辆识别代号」修缮逻辑（首次记录）

**背景**：统一爬取结果的 VIN 列格式，沿用库里 `vin_8` 的约定（`' '`/`'-'`/空 = 无信息）。

**改动**：
- `mj_convert.py`：新增 `import re` + `revise_vin()`（共享函数，供爬虫与转换复用）。
  - 规则：`','.join(re.findall(r'[A-Za-z0-9×]+', value or ''))`
  - 保留 `×` 掩码、按连续 [字母数字×] 切段、统一逗号分隔；`' '`/`'-'`/空 → 空串。
- `miit_crawler.py`：顶部 `from mj_convert import revise_vin`；`build_output_row` 拼行时对「车辆识别代号」列调用 `revise_vin`。

**输入 → 输出**：
- 输入：详情页解析出的原始「车辆识别代号」值（可能含空格/中文逗号/连续逗号等脏分隔符，或为 `' '`/`'-'`）。
- 输出：修缮后的「车辆识别代号」——`×` 掩码完整保留、段间统一英文逗号、无信息为空串。
- 落点：写入 `miit_gxb_<批次>.csv`；`mj_gxb_<批次>.csv` 经转换自动继承（两输出同步干净）。

**影响范围**：只影响**以后新爬的批次**；历史已爬文件（`miit_gxb_410.csv`/`mj_gxb_410.csv`）未追溯修改。主流程结构不变。

**验证**：
- `revise_vin` 9 组样例（真实多段 + 空格/中文逗号/连续逗号脏分隔 + `' '`/`'-'`/空）全部符合预期。
- `build_output_row` 修缮生效（脏分隔输入 → 干净逗号输出）。
- 回归：`convert_to_mj.py --batch 410` 输出与既有 `mj_gxb_410.csv` **逐字节一致**，转换行为未变。
